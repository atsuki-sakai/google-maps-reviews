# CSV入力

指定された1つのUTF-8 CSVを読みます。UTF-8 BOM、改行入り本文、引用符に対応します。列名は収集CLIの出力をそのまま使えます。

0.7.0以降の収集CLIは本文ありのみを保存します。評価のみを含む画面総件数とCSVの行数が異なっても、それだけで収集失敗とは判断しません。CSVの星平均は、入力された本文口コミの平均であり、店舗全体の平均星ではありません。

必須列は「口コミ本文」「星評価」（または text・rating）です。本文が空欄の行は評価のみとして集計し、星評価が空欄の本文は星不明として分析します。星は1〜5です。「本文」「評価」「review_text」「stars」も同義の列名として受け付けます。同じ項目の列を複数置かないでください。

任意の列は店舗名、投稿者、投稿日（画面表記）、店舗側の返信、口コミID、店舗URL、取得日時、本文の省略あり、日付範囲・日付の精度・期間判定などです。英語の列名は収集CLIのFIELDSと同じ名前です。口コミIDが未提供の場合はCSVの行番号を分析用IDに使い、Googleの口コミIDとして扱いません。同一本文の別行を勝手に重複削除しません。明示されたIDの重複・列数の不一致・不正な評価・複数施設は準備時にエラーとします。

元CSVをsource.csvとしてバイト単位で保持し、解析用source.jsonとそれぞれのSHA-256を記録します。準備後の原本変更は検証で拒否します。周辺ファイル・過去のJSONからデータを補いません。CSVの数式対策用アポストロフィも自動で削除しません。

CSVには通常Googleの総件数がないため、Google全件取得は未確認です。レポートには「入力CSVの全行を分析」と表示します。5行のCSVを渡した場合は5行の分析であり、未収集分を補完しません。期間指定のCSVも指定された行だけを分析します。日付の精度・期間判定がある場合は解釈に反映し、相対日付の推定を正確な投稿日として扱わないでください。
